# Supermarket Sales Performance & Interactive BI Dashboard

**Role:** BI & Data Analyst

## 📌 System Scope
Designed and developed an automated Power BI reporting system and KPI calculation framework using the Sample Superstore dataset to support management decision-making.

## 🛠️ Technical Implementation
- Imported and transformed raw data using **Power Query Editor**.
- Built a robust **star-schema** relational data model with an active **Date Hierarchy** table.
- Engineered advanced **DAX** measures (`Total Sales`, `Total Profit`, `Profit Margin %`, `Running Total`, and `Year-over-Year Growth`) alongside calculated columns (`Profitability Category` and `Shipping Delay`).

## 📊 Interactive Dashboards & UI
- Developed **3 comprehensive analytical report pages** (**Executive Analysis**, **Product Analysis**, and **Product Details**) featuring:
  - Custom KPI cards
  - Trend lines, regional performance charts, and category breakdowns
  - Global multi-tier slicers
  - Cross-page drill-through functionality

## 🧩 Tech Stack
- **Microsoft Power BI**
- **Power Query**
- **DAX**
- **Data Modeling**
- **ETL Pipeline Architecture**
- **Interactive Slicers**
- **Exploratory Data Analysis**
